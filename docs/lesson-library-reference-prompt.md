`C:\Screenshots\lesson-plan-library-borderless.png` as the visual targets.
At a 1536 × 1024 desktop viewport, render `/app?screen=library-loading&qa=1`
and `/app?screen=library&qa=1` and compare each screenshot with its target.

grid before changing small details. The loading view has a 324 px sidebar,
content starting at x=356, an 84 px search row starting at y=223, and cards
starting at y=334. Its six cards are about 290 px tall with pale cyan fills,
light-blue borders, rounded corners, and blue-gray skeletons. Match the title,
subtitle, icon block, label bar, and count bar widths and positions.

the extracted transparent PNG illustrations from the reference for the six
subjects. Use SVGs for the seven sidebar icons, notification bell, profile
avatar, and dropdown chevron. Clicking the Teacher control opens a menu with
a Profile entry. Preserve the existing screen sequence and smaller viewport
layouts.

After each adjustment, build and capture both screens at 1536 × 1024. Compare
card bounds, bar dimensions, colors, type sizes, icon sizes, and header
placement. Change only the mismatched measurements and repeat.
